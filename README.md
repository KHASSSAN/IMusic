IMusic 🎵

IMusic — учебное iOS-приложение на Swift, демонстрирующее основы работы с музыкальным плеером и интерфейсом iOS. Проект создан для практики iOS-разработки и изучения структуры реального приложения.

📱 О проекте

Проект показывает:

работу с аудио

базовую навигацию по экранам

использование UIKit / Swift

структуру iOS-проекта в Xcode

Подходит для начинающих iOS-разработчиков.

🛠 Используемые технологии

Swift

Xcode

UIKit

iOS Simulator

▶️ Как запустить

Клонировать репозиторий:

git clone https://github.com/KHASSSAN/IMusic.git


Открыть проект:

open IMusic.xcworkspace


Выбрать симулятор iPhone

Нажать Run ▶
